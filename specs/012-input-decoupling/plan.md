# Implementation Plan: Input Handling Decoupling

**Branch**: `012-input-decoupling` | **Date**: 2026-03-08 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/012-input-decoupling/spec.md`

## Summary

Extract duplicated mouse/keyboard input handling from the Fabric and Konva engine adapters into a shared GestureRecognizer that owns DOM event capture, gesture disambiguation, and coordinate conversion. Engine adapters implement a focused InputActionHandler interface for viewport manipulation, hit-testing, and drag suppression. Shared pure functions handle snap-to-grid, edge-anchor resize, and dimension quantization. Engines retain ownership of native drag/resize execution (ActiveSelection, Transformer) and all existing EngineEventMap emissions.
